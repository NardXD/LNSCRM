# CRM V3 - Customer Relationship Management System

A comprehensive CRM system built with Laravel 12 and modern frontend technologies.

## 📚 Documentation

**For developers working on this project, please refer to:**

- **[DEVELOPMENT_GUIDE.md](./DEVELOPMENT_GUIDE.md)** - Complete development guide covering frontend, backend, database, and coding conventions
- **[QUICK_REFERENCE.md](./QUICK_REFERENCE.md)** - Quick reference cheat sheet for common tasks and code snippets

## 🚀 Quick Start

```bash
# Install dependencies
composer install
npm install

# Set up environment
cp .env.example .env
php artisan key:generate

# Run migrations
php artisan migrate

# Build assets
npm run build

# Start development server
composer dev
```

## 🛠️ Technology Stack

- **Backend:** Laravel 12 (PHP 8.2+)
- **Frontend:** Tailwind CSS 4.0, Vite, Vanilla JavaScript
- **Database:** SQLite (default), MySQL/PostgreSQL supported
- **Build Tool:** Vite 7.0

## 📋 Features

- User Management
- Project Management
- Client Management
- Time Tracking
- Billing & Payments
- Employee Monitoring
- Ticket System
- **Admin Control Panel**
